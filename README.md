# 🚀 burppeter7-lab & sys-init-8

> Zwei Legenden. Eine Mission. Unklare Anforderungen.

## 👨‍🔬 Das Team

### burppeter7-lab

* Spezialgebiet: Kreative Lösungen für Probleme, die noch niemand hatte.
* Bekannte Fähigkeiten:

  * Burpt in Produktionsumgebungen
  * Findet Bugs durch reines Anstarren des Monitors
  * Commit-Nachrichten bestehen manchmal aus Emojis

### sys-init-8

* Spezialgebiet: Systeme starten, stoppen und gelegentlich verwirren.
* Bekannte Fähigkeiten:

  * Kennt jeden Linux-Fehlercode persönlich
  * Automatisiert alles – sogar das Vergessen von Meetings
  * Hat mindestens einmal versucht, Kaffee per Shell-Skript zu kochen
